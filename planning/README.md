# Planning Pack

This folder contains planning documents for an LLM-assisted build of a local desktop crypto trading bot.

Document order:

1. `00-project-brief.md`
2. `01-requirements.md`
3. `02-architecture.md`
4. `03-risk-register.md`
5. `04-strategy-spec.md`
6. `05-implementation-roadmap.md`
7. `06-llm-build-instructions.md`

Authoring rules for this pack:

- Do not treat unspecified details as approved.
- Prefer explicit `TBD` and `Open Question` entries over hidden assumptions.
- Keep safety, paper trading, and operator control ahead of speed to live trading.
- Treat this pack as a working baseline to revise, not a final specification.
